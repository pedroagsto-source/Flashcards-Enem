# MARCA.md · Identidade do seu escritório para o CHIP ADV

> **Como usar:** preencha este arquivo **uma vez**. Depois, sempre que for editar, anexe na conversa **CHIP_ADV.md + MARCA.md + mapa + vídeo** e escreva "Roda o CHIP ADV". Todo vídeo sai com a sua identidade.
>
> Apague os exemplos entre `[colchetes]` e escreva os seus dados. Deixe em branco o que não souber: o CHIP ADV usa o estilo escolhido para completar.

---

## 1. Quem aparece no vídeo

```yaml
nome_na_tela: "[Dra. Ana Souza]"           # como você quer ser chamado(a) na tela
escritorio: "[Souza Advocacia]"            # nome do escritório ou da sociedade
oab: "[OAB/SP 000.000]"                    # obrigatório na publicidade (CED, art. 44)
areas: ["[Família]", "[Sucessões]"]        # até 3
cidade: "[Campinas/SP]"                    # opcional
instagram: "[@anasouza.adv]"               # opcional
```

## 2. Estilo base

Escolha **um** dos 8 estilos do arquivo `ESTILOS.md` (veja as prévias no catálogo em PDF):

```yaml
estilo: "[sobrio-classico]"
# opções: sobrio-classico · editorial · moderno · minimal · premium-escuro · institucional · acolhedor · dinamico
```

## 3. Ajustes finos (opcional; substituem o estilo base)

```yaml
cor_principal: "[#0F1E33]"     # fundo dos cartões e textos grandes
cor_destaque: "[#B8955A]"      # palavra-chave da legenda, linhas, botões
cor_clara: "[#F4EFE6]"         # fundos claros e texto sobre a cor principal
fonte_titulo: "[Cormorant Garamond]"   # precisa existir no Google Fonts
fonte_texto: "[Inter]"
logo: "[logo.png]"             # anexe o arquivo junto; PNG com fundo transparente
```

## 4. Abertura e encerramento

```yaml
abertura: "[nenhuma]"           # nenhuma · nome (0,8 s com nome + área) · logo (0,8 s com logo)
assinatura_lateral: "[sim]"     # nome + OAB discretos no canto, em todo o vídeo
cartao_final: "[sim]"           # 1,5 s no fim: nome, OAB e @ do Instagram
frase_final: "[Informação jurídica com clareza.]"   # opcional, até 6 palavras
```

> A abertura deve ser curta. Os primeiros 1,5 segundos são do **hook**; por isso a opção padrão é "nenhuma" e a identificação vai na assinatura lateral e no cartão final.

## 5. Tom de voz na tela

```yaml
tratamento: "[você]"                     # você · o(a) senhor(a)
palavras_que_eu_uso: ["[direito]", "[orientação]", "[com segurança]"]
palavras_que_eu_evito: ["[garantido]", "[100%]", "[ganhe a causa]", "[promoção]", "[grátis]"]
emojis: "[não]"                          # não · poucos
```

## 6. Efeitos

```yaml
efeitos_favoritos: ["[07]", "[16]"]      # números do mapa; o CHIP ADV usa estes primeiro
efeitos_proibidos: ["[13]", "[14]"]      # nunca usar
intensidade: "[moderada]"                # discreta · moderada · intensa
```

## 7. Trilha

```yaml
trilha: "[piano e cordas, lenta]"        # descreva o clima; ou anexe a sua música
volume_trilha: "[baixo]"                 # baixo · médio
```

---

### Regras que o CHIP ADV segue com este arquivo
1. As cores e as fontes daqui **substituem** a paleta padrão do CHIP ADV em legendas, cartões e efeitos.
2. **Nome e OAB** aparecem pelo menos uma vez em todo vídeo (assinatura lateral ou cartão final).
3. Nenhum texto na tela usa as **palavras que você evita** nem promete resultado.
4. Efeitos proibidos nunca entram; os favoritos têm prioridade quando combinarem com a fala.
5. Se o logo vier anexado, ele entra só no cartão final e na abertura (nunca por cima do rosto).
